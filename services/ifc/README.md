# IFC service

FastAPI + IfcOpenShell service that turns a `BuildResult` into an IFC4 massing file and checks IFC files against `app/massing.ids` (SPEC §7, §13).

## Run

```bash
cd services/ifc
python3 -m venv .venv            # Python 3.12+
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload --port 8000
```

Docker:

```bash
docker build -t feasibility-ifc services/ifc
docker run --rm -p 8000:8000 feasibility-ifc
```

Environment: `IFC_MAX_BODY_BYTES` (default 52428800, 50 MB; larger bodies get 413).

## Endpoints

| Method | Path | Body | Response |
| --- | --- | --- | --- |
| GET | `/health` | | `{"ok": true, "ifcopenshell": "<version>"}` |
| POST | `/ifc/build` | JSON (see below) | `application/x-step` IFC4 file |
| POST | `/ifc/validate` | raw IFC bytes (`application/x-step` or `application/octet-stream`) | `{"ok": bool, "schema", "ids", "checks": [...]}` |

`POST /ifc/build` body (coordinates are local metres east/north of the site origin, footprints are rings without a closing vertex; clockwise rings are reversed):

```json
{
  "project": {"id": "prj_x", "name": "Projet", "optionName": "Option A", "versionId": "ver_x"},
  "site": {"origin": {"lon": -17.4677, "lat": 14.7167, "crs": "EPSG:32628"},
           "originUtm": [234285.72, 1628446.44], "northAngle": 0,
           "plot": [[0,0],[40,0],[40,30],[0,30]]},
  "blocks": [{"id": "blk_A", "name": "Bloc A", "footprint": [[5,5],[29,5],[29,21],[5,21]], "heightM": 20.0,
              "storeys": [{"index": 0, "elevationM": 0, "heightM": 4.5, "areaM2": 384, "use": "retail"}]}],
  "attribution": "optional text"
}
```

Invalid input returns 422 `{"error": "invalid_request", "message": "...", "detail": [{"path", "message", "type"}]}`.

Output: IfcProject (m, m², m³, degree) → IfcSite (IfcMapConversion + IfcProjectedCRS, RefLatitude/RefLongitude, plot footprint) → IfcBuilding per block → IfcBuildingStorey per storey (`RDC`, `R+1`, …, `R-1`; Elevation set) → per storey one IfcSpace (LongName = use, `Qto_SpaceBaseQuantities`) and one IfcBuildingElementProxy massing solid.

`northAngle` (degrees) follows `packages/sun`: the local +Y axis points at azimuth `northAngle`, clockwise from north. So `XAxisAbscissa = cos θ`, `XAxisOrdinate = −sin θ`, and the context TrueNorth is `(−sin θ, cos θ)`. Grid north is treated as true north.

GlobalIds are deterministic: `ifcopenshell.guid.compress(uuid5(NS, key).hex)` with keys `project:{versionId}`, `site:{versionId}`, `building:{blockId}`, `storey|space|proxy:{blockId}:{index}`. Relationships and property sets get ids derived from creation order. The header timestamp is fixed, so the same input gives the same bytes.

## Test

```bash
cd services/ifc
.venv/bin/python -m pytest
```

The IDS file is generated by `scripts/make_ids.py` (`.venv/bin/python scripts/make_ids.py`), which also validates it against the IDS 1.0 XSD.
